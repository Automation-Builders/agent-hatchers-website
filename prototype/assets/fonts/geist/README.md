# Geist

`Geist-latin.woff2` and `OFL.txt` are copied unchanged from Hermes-Dashboard
`LibreChat/client/public/fonts/geist/`, the dashboard's own self-hosted Latin
subset (variable weights 100–900, SIL Open Font License). The playground's
dashboard and onboarding screens use it so they match the live dashboard
without a Google Fonts request.
